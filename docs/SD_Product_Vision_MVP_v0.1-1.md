# Security Depot Field Service Management System
## Product Vision & MVP Scope
### Version 0.1 (Draft)

# 1. Executive Summary

Security Depot currently manages field operations through a combination of:
- Outlook Email
- Google Calendar
- Slack
- Excel spreadsheets
- Technician notes

The goal of this system is to create a centralized operational platform that improves visibility, accountability, scheduling, and historical tracking.

# 2. Problem Statement

Today:
- Customer requests arrive through email.
- Managers manually review and assign work.
- Calendar events are manually created for technicians.
- Technicians add free-text notes inside calendar events.
- Follow-up visits, required parts, and unfinished work can be difficult to track.

# 3. Vision

Create a centralized field service management platform specifically designed for:
- Security Systems
- Access Control
- CCTV
- Intercoms
- Automatic Doors
- Building Security Infrastructure

# 4. Primary Users

## Service Manager
- Reviewing incoming requests
- Creating jobs
- Assigning technicians
- Tracking workload

## Office / Service Coordinator
- Entering customer requests
- Communicating with customers
- Updating job information

## Field Technician
- Viewing assigned work
- Updating visit status
- Recording work completed
- Requesting parts

# 5. Core Concepts

## Site
A physical location containing:
- Address
- Customer Contacts
- Installed Systems
- Site History

## Job
A customer request or project.

## Visit
A single technician visit.

# 6. MVP Goals

- Create Jobs
- Assign Jobs
- Schedule Visits
- Generate Calendar Events
- Track Status
- View Site History

# 7. Technician Workflow

1. Manager creates Job
2. Manager assigns Job
3. Calendar Event created automatically
4. Technician opens event
5. Technician submits visit update

# 8. Success Criteria

- Every customer request becomes a Job.
- Every technician visit is recorded.
- Return visits are tracked.
- Required parts are tracked.
- Site history is searchable.
